# Smart Absensi IoT

Sistem informasi absensi mahasiswa berbasis IoT menggunakan ESP32
dan fingerprint AS608.

## Teknologi
- ESP32
- AS608
- PHP
- MySQL
- HTML
- CSS
- JavaScript
- XAMPP
- Arduino IDE

## Fitur
- Login Admin, Dosen, Mahasiswa
- Registrasi fingerprint
- Absensi menggunakan fingerprint
- Validasi KRS
- Validasi jadwal perkuliahan
- Rekap kehadiran
- Persentase kehadiran
- Status kelayakan

## Cara Menjalankan
1. Install XAMPP.
2. Copy project ke folder htdocs.
3. Buat database `smart_absensi`.
4. Import file `smart_absensi.sql`.
5. Sesuaikan konfigurasi database.
6. Jalankan Apache dan MySQL.
7. Buka project melalui browser.
